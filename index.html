Webflow CMS

Wire the book images

Add three image fields to your CMS item, then bind each one to an image element inside the Collection Item and add the matching attribute.

If you do not have a separate back image, reuse the front face. If you do not have a separate cover image for the binding edge, reuse the spine image you already have.

Front face

Bind the CMS image field for the front cover to an Image element and add data-bookshelf-cover.

This is the face you see when the book is closed and facing forward.

Back face

Bind the CMS image field for the back cover to an Image element and add data-bookshelf-back.

If you do not have a separate back image, reuse the front face.

Binding edge

Bind the CMS image field for the spine or binding edge to an Image element and add data-bookshelf-spine.

This is the thin edge facing the viewer when the shelf rotates.

CMS item wrapper:

<div data-bookshelf-cms-item>...</div>

Suggested Webflow setup:

Front image field = cover
